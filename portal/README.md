# portal

Owner portal for Second Brain: a wiki workspace (file tree, tabs and split panes, page info with
backlinks and a local graph, a graph of the whole wiki, a quick switcher), chat import and batch
processing, home with ideas, docs, endpoint dashboard, usage and provider API keys. The wiki
workspace is progressive enhancement over server-rendered pages: `static/js/workspace/`, fed by
the JSON routes listed at the top of `src/portal/wiki.py`.
See [docs/portal.md](../docs/portal.md) and the repository root README.
