# The portal

The portal is a small website for the owner at **http://localhost:3090** (`PORTAL_PORT`,
published on the host's 127.0.0.1 only, never routed through Tailscale Funnel). On it you can:

- **Read the wiki.** A workspace with a file tree, tabs side by side, each page's links,
  backlinks and outline, a graph of the whole wiki, search and a quick switcher (Ctrl/⌘+K). It
  shows the index, a folder per type, `log.md`, recent changes and drafts.
- **Review proposals.** Low-trust writes (for example a page written from an `external`
  source, such as an inbox note) wait under **Wiki › Proposals** until you accept or reject
  them; drafts get **Mark reviewed**.
- **Manage connected apps.** **Settings › Connected apps** lists every app connected to the MCP
  connector and turns its access to private pages on or off.
- **Read the docs.** The README and `docs/`, with links between them.

## Signing in

User name `owner` (`OWNER_USERNAME`) and the **admin password** from the setup wizard: the same
login as the MCP connector. There is no separate account.

- Sessions are kept on the server; the browser only holds a random ID in an `HttpOnly`,
  `SameSite=Strict` cookie. You are signed out after 30 minutes of inactivity
  (`PORTAL_SESSION_IDLE_S`), after 12 hours in any case (`PORTAL_SESSION_MAX_S`), and whenever
  the portal restarts.
- Private-access changes ask for the password again when you have not entered it in the last
  15 minutes.
- After 5 wrong attempts, sign-in is locked with a growing delay, both per IP and overall.

## How it reads the wiki

Through a read-only JSON API on the brain's internal listener (`brain:8081`, Docker network
only), with its own token (`data/secrets/portal_token`, generated by the brain). The only writes
are the owner's own actions: deciding proposals and marking pages reviewed, written with trust
`owner`. The portal mounts `data/secrets/` read-only (for that token and the admin password
hash) and keeps its sessions and audit log in `data/portal/`.

The portal's other pages from the Second Brain it was forked from (ideas, patterns, dreams, the
assistant, chat import, API keys, usage) are not registered; see
[FORK_NOTES.md](FORK_NOTES.md).
