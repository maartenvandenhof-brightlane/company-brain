MCP connector

How to get a Tailscale auth key (once, about 5 minutes)
  1. Sign in to the Tailscale admin console (a free account is enough).
  2. Under DNS, enable MagicDNS and HTTPS Certificates.
  3. Under Access controls, allow Funnel for the brain: add this to the tailnet policy file (merge it into an existing nodeAttrs): 
    "nodeAttrs": [
  { "target": ["autogroup:member"], "attr": ["funnel"] }
]
  4. Under Settings → Keys, Generate auth key with Reusable off and Ephemeral off, and paste it below. It is used once: the sidecar then stays logged in.

Google account

How to get an OAuth client (once per company, about 5 minutes)
  1. In the Google Cloud console, create a project with your company's Google account.
  2. Under APIs & Services → Library, enable the Google Drive API and the Google Tasks API.
  3. Under OAuth consent screen, choose user type Internal (only your company's accounts; Google then never has to verify the app).
  4. Under Credentials → Create credentials → OAuth client ID, choose type Web application and add this authorized redirect URI exactly:
    {{ redirect_uri }}
  5. Paste the client id and secret below, or upload the JSON file Google offers.
