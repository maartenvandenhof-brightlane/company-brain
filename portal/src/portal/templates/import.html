What gets stored

{{ icon("check") }}After you confirm the preview

  • One clean transcript per new conversation, as a raw source under raw/chats/.
  • Secrets such as API keys, tokens and passwords are replaced by [secret removed].
  • Conversations imported before stay as they are: never changed, never duplicated. If one has new messages since, only those are added, as a continuation.

{{ icon("x-circle") }}Never stored

  • The export file itself: it is deleted as soon as it has been read.
  • Thinking, tool output and images. Tool calls and images become short placeholders.
  • Projects, and the branches of an edited ChatGPT conversation you did not keep.
